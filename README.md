# CampusEats Task Tracker

A simple task management system for managing tasks in the CampusEats project.

## Features

- Add new tasks
- View task list
- Update tasks
- Delete tasks

## Technologies

- React
- ASP.NET Core
- Git & GitHub

## Installation

```bash
git clone https://github.com/IT24100715/campuseats-task-tracker.git
cd campuseats-task-tracker
```

## Usage

Run the project and open the application in your browser.
